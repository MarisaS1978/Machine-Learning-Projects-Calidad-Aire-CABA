## 🚀 Proyecto Destacado

### 🌎 Clasificación de la Calidad del Aire — Buenos Aires, Argentina

**Machine Learning Supervisado | Clasificación Binaria**

Proyecto de Machine Learning enfocado en identificar registros horarios con concentraciones elevadas de PM10 en la Ciudad Autónoma de Buenos Aires (CABA), utilizando datos de monitoreo de la calidad del aire.

**Aspectos destacados del proyecto:**

- Limpieza y preprocesamiento de datos.
- Análisis Exploratorio de Datos (EDA).
- Tratamiento de valores faltantes y valores atípicos (*outliers*).
- Ingeniería de características y creación de variables temporales.
- Preprocesamiento de datos mediante *Pipelines* de Scikit-learn.
- Entrenamiento y comparación de modelos.
- Validación cruzada y ajuste de hiperparámetros.
- Evaluación e interpretación de modelos.

**Modelos de Machine Learning utilizados:**

- Regresión Logística (*Logistic Regression*)
- Bosque Aleatorio (*Random Forest*)
- K vecinos más cercanos (*K-Nearest Neighbors – KNN*)

**Modelo con mejor rendimiento:** Random Forest

**Principales resultados en el conjunto de prueba:**

- F1-score: 0.348
- Precisión (*Precision*): 0.369
- Exhaustividad (*Recall*): 0.329
- ROC-AUC: 0.836

📂 **Ver notebook:** [Air Quality CABA – Classification](projects/air-quality-caba/notebooks/air-quality-CABA.ipynb)

## 🚀 Featured Project

### 🌎 Air Quality Classification — Buenos Aires, Argentina

**Supervised Machine Learning | Binary Classification**

A Machine Learning project focused on identifying hourly records with elevated PM10 concentrations in the City of Buenos Aires (CABA), using air quality monitoring data.

**Project highlights:**
- Data cleaning and preprocessing.
- Exploratory Data Analysis (EDA).
- Missing values and outlier treatment.
- Feature engineering and temporal variables.
- Data preprocessing with Scikit-learn Pipelines.
- Model training and comparison.
- Cross-validation and hyperparameter tuning.
- Model evaluation and interpretation.

**Machine Learning models:**
- Logistic Regression
- Random Forest
- K-Nearest Neighbors (KNN)

**Best performing model:** Random Forest

**Key test results:**
- F1-score: 0.348
- Precision: 0.369
- Recall: 0.329
- ROC-AUC: 0.836
