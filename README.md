## 🚀 Featured Project

### 🌎 Air Quality Classification — Buenos Aires, Argentina

**Supervised Machine Learning | Binary Classification**

A Machine Learning project focused on identifying hourly records with elevated PM10 concentrations in the City of Buenos Aires (CABA), using air quality monitoring data.

**Project highlights:**
- Data cleaning and preprocessing.
- Exploratory Data Analysis (EDA).
- Missing values and outlier treatment.
- Feature engineering and temporal variables.
- Data preprocessing with Scikit-learn Pipelines.
- Model training and comparison.
- Cross-validation and hyperparameter tuning.
- Model evaluation and interpretation.

**Machine Learning models:**
- Logistic Regression
- Random Forest
- K-Nearest Neighbors (KNN)

**Best performing model:** Random Forest

**Key test results:**
- F1-score: 0.348
- Precision: 0.369
- Recall: 0.329
- ROC-AUC: 0.836

📂 Project files: `projects/air-quality-caba/`
